## Changes

- Added an original SushiTray icon for the macOS app and menu header.
- Shortened the README and added usage notes for startup update checks and the
  optional BF16 n-gram table on 48 GB Macs.
- Added a reusable agent skill for choosing Sushi models and configuring
  `sushi serve` on Apple Silicon.

## Fixes

- Wait for the managed Sushi server to stop before updating the Sushi CLI. If
  the server was running, start it again after the update attempt and report
  any restart failure.

## Compatibility

Requires macOS 13 or newer on Apple Silicon, and Sushi 1.5.0 or newer.
