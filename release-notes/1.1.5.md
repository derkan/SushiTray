## Fixes

- Refresh Homebrew before upgrading SushiTray so an out-of-date tap does not
  leave the old app installed. The updater verifies the installed version
  after the upgrade.
- Publish the Homebrew cask version and ZIP checksum automatically from the
  GitHub Actions release workflow.

## Compatibility

Requires macOS 13 or newer on Apple Silicon, and Sushi 1.5.0 or newer.
