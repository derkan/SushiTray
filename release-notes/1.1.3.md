## Fixes

- Verify the installed SushiTray and sushi versions after an update before reporting success. A successful Homebrew command that leaves the old version installed now reports a failure with the installed and expected versions instead of asking to relaunch into the same update prompt.
- Read the updated app's Info.plist directly from disk so the version check does not use the running app's cached bundle metadata.
- Explain when Homebrew may be behind GitHub Releases or a different app copy was updated.

## Validation

- Add regression coverage for successful no-op upgrades, missing or below-target versions, command failures, and replaced app metadata.

## Compatibility

Requires macOS 13 or newer on Apple Silicon, and Sushi 1.5.0 or newer.
